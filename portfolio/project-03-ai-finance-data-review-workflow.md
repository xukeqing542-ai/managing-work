# 项目3｜AI辅助财务数据处理与可视化复核流程

**AI-Assisted Finance · Data Cleaning · Exception Review · Human-in-the-Loop**

> 项目性质：个人模拟项目（Independent Simulation）

## 项目目标
将费用/付款审核中的重复性数据工作拆解为可追溯流程，探索 Excel、基础 Python 与 AI 工具在财务数据清洗、匹配、异常识别、复核和可视化中的应用。

## 核心工作
- 基于 **240 行**模拟费用/付款数据搭建 Raw-Clean-Match-Exception-KPI-Human Review 流程。
- 进行字段标准化、跨表匹配，并识别重复发票、缺失 PO、异常金额、空字段及文本不一致等问题。
- 使用 Excel、基础 Python 与 ChatGPT/Codex 辅助公式、脚本、规则设计和异常解释。
- 设置人工复核节点，通过对账、合理性检查与日志记录保证输出可追溯。
- 设计 KPI / Power BI-ready 字段，为后续管理看板和异常监控提供结构化数据基础。

## 关键结果
- 数据量：**240 records**
- 需复核异常：**76 records**
- 异常率：**31.7%**
- 重复更新练习：约 **60 min → 25 min**
- 时间下降：约 **58%**

## 工具与方法
Excel、Python（基础 pandas/openpyxl 应用）、SQL 式规则、ChatGPT/Codex、Power BI/Power Query 基础、Human-in-the-Loop Review。

## 能力映射
适用于财务数字化、Finance Transformation、AI-Native Analyst、财务分析、财务BP岗位，展示“问题拆解 → 数据处理 → AI协同 → 人工校验 → KPI/可视化 → 流程优化”的完整思路。

## 真实性说明
项目数据为个人构造的模拟数据，用于能力训练和流程验证；不代表真实企业付款数据或客户生产环境。
