## Portfolio Overview

### 1. Enterprise Performance Management / Budget & Decision Analytics
- 搭建 12 个月 **销量 → 价格 → 收入 → 成本 → CapEx → 营运资金 → 现金流** 联动模型。
- 年度预算收入 **RMB 3.672m**，实际收入 **RMB 3.642m**，识别收入差异约 **RMB -29.5k**。
- 完成 **Budget vs Actual、Gross Profit Bridge、Price-Volume-Mix (PVM)** 分析，并形成管理看板。
- 将业务驱动变化转化为经营影响、风险提示和行动建议，训练 Business Finance / FP&A 决策支持能力。

### 2. AI-Assisted Finance Data Workflow
- 基于 **240 行模拟费用/付款数据**构建 Raw → Clean → Match → Exception → KPI → Human Review 流程。
- 识别 **76 条需复核记录，异常率 31.7%**，覆盖重复发票、缺失 PO、异常金额、空字段及文本不统一等问题。
- 使用 **Excel + Python + SQL-style rules + ChatGPT/Codex** 辅助数据清洗、跨表匹配、异常识别和 SOP 沉淀。
- 将重复更新练习从约 **60 分钟缩短至 25 分钟，效率提升约 58%**。
- 保留人工复核、异常日志和处理状态，强调可追溯性和 Human-in-the-Loop 控制。

### 3. Visa Inc. Public-Company Analytics / Forecast / DCF
- 基于 Visa FY2023-FY2025 10-K 与 FY2026 Q3 10-Q 公开数据建立历史/LTM 指标。
- 搭建 **2026E-2030E 五年 Forecast**，分析收入、利润率、FCF 与业务驱动。
- 构建 downside / base / upside 三情景及 **5×5 WACC / Terminal Growth** 敏感性矩阵。
- 强调假设挑战、风险区间和管理式表达，而非单点估值结果。

### 4. China Unicom Operating & Cash-Flow Analysis
- 基于公开业绩资料复算：2025 年收入约 **+0.7%**、经营利润约 **+16.0%**、自由现金流约 **+28.5%**。
- 对 2026H1 经营现金流增长与归母净利润下降的背离进行经营分析。
- 使用“**事实 → 原因 → 风险 → 建议**”框架组织分析输出，训练行业经营分析与管理沟通能力。

### 5. Financial Close / Controls Simulation
- 将 **30 笔模拟业务**拆分为 **60 行借贷分录**，覆盖现金、AR、存货、固定资产、预付、收入、费用及税费预提。
- 借贷累计各 **RMB 1,723,300**，通过 Trial Balance；模拟 P&L 净利润 **RMB 88,700**，Balance Sheet Check = 0。
- 设计 **12 项月结/内控检查**，形成 Source Document → Review → Journal → TB → P&L / Balance Sheet 可追溯链。

## Working Principles

1. **Business problem first** — clarify the decision question before building the model.
2. **Traceable data** — retain source, assumptions, calculation logic and review evidence.
3. **AI as copilot, not authority** — challenge AI output with reconciliations, reasonableness tests and human review.
4. **Insight to action** — convert financial analysis into operating implications and actionable recommendations.

## Project Boundary

- Public-company projects use publicly available financial disclosures and are **Independent Projects**.
- ERP / finance workflow / close-control exercises are **Simulation or academic-practice projects**.
- No simulated or public-data project is represented as real employer production work.
