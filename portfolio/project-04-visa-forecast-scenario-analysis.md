# 项目4｜Visa Inc.：上市公司经营分析、Forecast 与情景建模

**Public Company Analysis · Forecast · DCF · Scenario & Sensitivity Analysis**

> 项目性质：基于 Visa 公开财报资料的独立分析项目（Public-data Independent Project）

## 项目目标
基于 Visa FY2023-FY2025 10-K 与 FY2026 Q3 10-Q，建立历史/LTM指标、五年预测与情景分析框架，将公开财务数据转化为经营洞察、风险区间和结构化管理表达。

## 核心工作
- 整理收入、利润率、自由现金流及关键业务驱动指标，建立历史与 LTM 分析框架。
- 搭建 **2026E-2030E 五年 Forecast**，把支付业务驱动映射至 Revenue、Operating Income 与 FCF。
- 设置谨慎 / 基准 / 乐观三种情景，测试不同经营假设对利润与现金流的影响。
- 建立 **5×5 WACC / Terminal Growth** 敏感性矩阵，用区间方式表达估值与不确定性。
- 将结果组织为管理式洞察，强调关键假设、风险信号和决策区间，而不是单点预测。

## 关键输出
- FY2025 Revenue：约 **US$40.0bn**
- FY2025 FCF：约 **US$21.6bn**
- **5-year Forecast**
- **3-scenario analysis**
- **5×5 sensitivity matrix**

## 工具与方法
Excel、公开财报分析、Driver-based Forecast、DCF、Scenario Analysis、Sensitivity Analysis、英文财务资料阅读。

## 能力映射
适用于财务分析、FP&A、经营分析、投资分析及国际化财务岗位，重点展示英文财报阅读、预测建模、情景分析和结构化表达能力。

## 真实性说明
项目仅基于 Visa 公开披露资料进行个人独立分析；预测和估值假设为个人练习，不代表 Visa 官方预测或投资建议。
